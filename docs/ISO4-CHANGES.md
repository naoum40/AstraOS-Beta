# ISO 4 (v0.4) — Changelog

## Added

- **AstraPass** — password manager with AES-GCM 256-bit encryption + PBKDF2 key derivation
- **Astra Widgets** — desktop widgets (Clock, Calendar, Weather, Battery)
- **Astra Sticky Notes** — colored draggable notes on desktop
- **Astra Minesweeper** — 9x9 grid, 10 mines, flag + flood-fill
- **Astra Tic-Tac-Toe** — 3x3 grid, score tracking
- **Astra Snake** — classic snake game, arrow keys

## Build

```bash
make build-iso
```
