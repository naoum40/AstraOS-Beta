# ISO 3 (v0.3) — Changelog

## Added

- **Astra Settings** — system configuration panel (Rust + GTK4-rs)
  - Account, Personalization, System, About pages
- **Astra Screenshot** — screenshot tool (full/region/window)
- **Astra Photos** — simple image viewer with zoom + folder navigation
- **Brave browser** (replaces Firefox)
- **VLC** media player
- **File associations** configured (.pdf, .txt, .png, .mp4, etc.)

## Changed

- Firefox → Brave (privacy-focused, faster)
- Added xdg-utils + mime-types for file associations

## Build

```bash
make build-iso-3
```
